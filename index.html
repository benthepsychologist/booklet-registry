Using it

Point the renderer's Add a module button at this registry and these appear in the list. The renderer fetches this one file — about 4.4KB — and downloads a module's own file only when somebody adds it.

Adding one

A module is one v0.12 booklet file — Markdown, with the design as callout lines and no JSON except a widget's own data. See SPEC.md. Open a pull request; see CONTRIBUTING.md. This registry is an index, not an endorsement or safety certification.
